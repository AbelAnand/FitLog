- Workout timer: `workouts.started_at` (default now()) drives the ticking header pill via `src/lib/duration.ts`; a session is 'live' only if unfinished, dated today, and under 6 h. Finished length = finished_at − started_at, shown on rows when between 1 min and 6 h.
- Themes: `src/lib/theme.ts` + `:root[data-theme=…]` blocks in `src/styles/app.css` override the token variables (Tailwind utilities resolve to `var(--color-*)`). Light themes set `color-scheme: light` and flip the native status bar style. Anything drawn outside CSS (charts) reads tokens via `useThemeTokens()`. Titles use the `.page-title` class so a theme can change their typographic voice (Ember is uppercase/heavy).
- Keyboard: number pads rely on the Capacitor accessory bar's Done button (keep `setAccessoryBarVisible(true)`); a capture-phase pointerdown in `main.tsx` blurs inputs on any tap outside a field; sheets blur on touchmove; the WKWebView uses `keyboardDismissMode = .interactive` and `allowsBackForwardNavigationGestures = true` (swipe from the left edge goes back).
- Editor header: the sticky bar carries `env(safe-area-inset-top)` itself (main has no top padding) so it never slides under the status bar.
